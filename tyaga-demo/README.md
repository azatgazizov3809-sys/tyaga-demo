# ТЯГА — рабочее демо на Python

[Открыть интерактивное демо](https://tyaga-python-demo.mcazay.chatgpt.site)

Четыре раздела: легковые автомобили, грузовики и спецтехника, мотоциклы и мототехника, водный транспорт. Адаптивный интерфейс, светлая и тёмная темы. Данные и бизнес-правила обрабатывает Python. HTML, CSS и JavaScript отвечают за интерфейс. Запчастей и аксессуаров нет.

Переключатель с луной и солнцем находится в шапке на компьютере и телефоне. Тёмная тема использует утверждённое сочетание графита и бирюзы. Выбор сохраняется в этом браузере и применяется до загрузки интерфейса; переключение не перезагружает страницу и не сбрасывает заполненные формы.

## Запустить на компьютере

Нужен установленный Python 3.10 или новее. Дополнительные библиотеки не требуются.

1. Клонируйте этот репозиторий или распакуйте его ZIP-архив с GitHub.
2. Откройте терминал в папке проекта.
3. Выполните на macOS или Linux:

```bash
python3 app.py --open
```

На Windows:

```powershell
py -3 app.py --open
```

Браузер откроется автоматически. Адрес — `http://127.0.0.1:8000`. Если порт занят, добавьте `--port 8001`. Остановка сервера — Ctrl+C. Локальная версия работает без интернета. Не открывайте `dist/index.html` двойным щелчком: для запуска нужен сервер.

Для проверки на телефоне в той же Wi-Fi сети запустите `python3 app.py --host 0.0.0.0` и откройте `http://<локальный-IP-компьютера>:8000`. ОС может попросить разрешить входящее соединение. Это сервер для демонстрации, без конфигурации публичного промышленного хостинга.

## Данные и ограничения демо

По умолчанию открыт аккаунт Азата. В меню «Сценарии демо» можно переключиться на Илью или Анну — модератора. Вход по любому корректному тестовому номеру с кодом `123456` открывает аккаунт Азата. Прямой путь кабинета модератора — `#/moderator`. Это явное переключение демо-ролей, а не промышленная система авторизации.

Python проверяет роль при каждом решении модератора. Возврат и снятие требуют причины; публикация — заполненного чек-листа. Устаревшее решение отклоняется по версии объявления. Редактирование активного объявления и восстановление из архива отправляют его на новую проверку. История содержит автора, время, причину и смену статуса.

Обновление данных версий 1 → 2 → 3 добавляет новые разделы и объявления без сброса ранее сохранённых объявлений, переписок, профиля и избранного. Неизвестные значения не считаются нулём; по умолчанию числовые фильтры исключают их. Моточасы и пробег хранятся отдельно. Ссылку на поиск можно скопировать, поиск — сохранить.

Все объявления, продавцы, контакты, переписки и сеансы вымышлены. Фотографии созданы для демонстрации. SMS, звонки, email и внешние сообщения не отправляются. Проверка объявлений и ответы собеседника запускаются кнопками демо. Уведомления сохранённых поисков — сохраняемые настройки и счётчики внутри приложения, без фоновой email-рассылки. При загрузке своих фото сохраняется содержимое файла; используйте тестовые материалы.

Локальный сервер сохраняет изменения в `tyaga.sqlite3` рядом с `app.py`. Браузер получает отдельную демо-сессию через cookie. Азат и Илья внутри этой сессии разделяют объявления и переписки; разные браузеры или устройства имеют независимые наборы данных. Сброс затрагивает текущую демо-сессию.

Опубликованная версия запускает ту же Python-логику через Pyodide в Web Worker и сохраняет данные в IndexedDB браузера. Первое открытие загружает Python; последующие загрузки используют кеш браузера. Очистка данных сайта удалит ваши изменения. Это позволяет проверить сценарии онлайн без общего сервера и без передачи тестовых данных другим пользователям. Это интерактивный прототип, а не готовая многопользовательская площадка.

## Структура

- `engine.py` — данные, поиск, проверки полей и прав владельца, все изменения состояния.
- `catalog_schema.py` — категории, единицы измерения, общая схема фильтров и формы подачи.
- `app.py` — HTTP API и SQLite на стандартной библиотеке Python.
- `dist/` — адаптивный интерфейс, изображения и браузерный транспорт.
- `dist/python-worker.js` — запуск Python в опубликованном демо.
- `tests/` — сценарные проверки логики и локального HTTP API.
- `build.py` — обновление браузерной копии Python-логики и архива проекта.

В репозиторий включена браузерная среда Pyodide (`dist/runtime/`) с файлами лицензий. Для запуска через `app.py` она не нужна. Архив, который создаёт `build.py`, не содержит этой среды и предназначен для локального Python-сервера.

Ссылка выше ведёт на опубликованное демо. Этот репозиторий хранит исходники; GitHub Pages автоматически не включается. Для публикации в подпапке GitHub Pages потребуются изменения абсолютных путей ресурсов.

## Проверки

```bash
python3 -m unittest discover -s tests -v
node tests/test_pyodide.mjs
```

Тесты используют временную SQLite-базу и не меняют ваши данные. Проверяются фильтры и сортировка, публикация и модерация, черновики, права владельца, архив, избранное, сравнение, диалоги двух ролей, сохранённые поиски, профиль, поддержка, вход, сохранение и изоляция HTTP-сессий.

## Браузерная среда

Опубликованное демо использует [Pyodide 0.29.4](https://pyodide.org/en/0.29.4/) — CPython, собранный в WebAssembly. Лицензии среды размещены в `dist/runtime/` опубликованной версии. Для локального запуска используется ваш Python. Интерфейс без дополнительных JS-фреймворков и внешних шрифтов.

## Рабочее место модератора

- Очередь: поиск по номеру, транспорту или продавцу; фильтры по разделу, типу продавца, приоритету, ожиданию больше суток, повторной проверке и замечаниям.
- Приоритет поднимает объявление в очереди. Отложить можно на 15 минут, час или сутки; после срока оно снова доступно в основной очереди при обновлении. Ручное возвращение доступно в любой момент.
- Обзор, характеристики, история и служебные заметки — отдельные вкладки. На телефоне очередь и выбранное объявление — отдельные представления.
- Чек-лист и черновик комментария хранятся в браузере отдельно для роли, объявления и версии. Изменение объявления сбрасывает применимость старых отметок.
- Возврат и снятие открывают форму с шестью редактируемыми шаблонами причин. Комментарий поступает продавцу. Служебные заметки ему не отправляются.
- После решения открывается следующее объявление из текущей выборки; настройку можно отключить. J/K (также О/Л) переключают объявления, кроме ввода текста.
- При повторной отправке видны изменения цены, описания, характеристик и состава фото относительно последнего решения. Для решений предыдущей версии без снимка показано объяснение, без выдуманных различий.
- Журнал фильтруется по периоду, разделу и событию; можно выгрузить текущую выборку в CSV. Приоритеты, откладывание и заметки также записываются в журнал.

Статистика решений за сегодня рассчитывается по времени Москвы. Подсказки о пустых полях и возможных дублях — проверки заполнения, не автоматическая проверка подлинности техники.

Проверка этой версии: Python/HTTP-тесты, реальная среда Pyodide и рендеринг шаблонов без браузера. Визуальная проверка на устройствах требует доступного браузерного окружения.
