# ТЯГА — продолжение работы на Mac

Это готовое интерактивное демо на Python, перенесённое из облачной задачи 19.10.2026.

## Текущая задача
Пользователь просит загрузить эту версию на свой GitHub и прислать ссылку. GitHub открыт и авторизован в Mozilla Firefox на Mac. Предыдущий агент не загрузил файлы: облачная сессия не имела доступа к Mac. Репозиторий GitHub ещё не создан. Работать с существующим аккаунтом пользователя, не создавать новый аккаунт. Предложенное имя нового репозитория — tyaga-demo, видимость по умолчанию — private. Не перезаписывать существующий одноимённый репозиторий без проверки.

## Что уже сделано
- Адаптивный каталог, категории и поиск с фильтрами.
- Светлая и тёмная темы с переключателем.
- Личный кабинет, объявления, избранное, сравнение, сообщения, профиль.
- Доработанный кабинет модератора: очередь и фильтры, публикация/возврат, приоритет, отложенная проверка, служебные заметки, сравнение исправлений, журнал и CSV.
- Подготовлен чистый экспорт из версии 5 опубликованного демо.
- Проверены 27 тестов Python и HTTP; все прошли.

Действующее демо: https://tyaga-python-demo.mcazay.chatgpt.site

## Запуск
Нужен Python 3.10+. Дополнительных библиотек Python нет. Из папки проекта:

```bash
python3 app.py --open
```

Адрес: http://127.0.0.1:8000. Код демо-входа: 123456. Переключатель «Сценарии демо» содержит Азата, Илью и Анну-модератора.

## Важные решения
Категории: легковые автомобили; грузовики и спецтехника; мотоциклы и мототехника; водный транспорт. Запчастей и аксессуаров нет. CRM отложена, автозагрузка ожидает файлов дилеров. Ссылка на скачивание проекта удалена из интерфейса сайта по просьбе пользователя — не возвращать её.

Это демонстрация: вымышленные данные, простое переключение ролей, локальное хранение. Не выдавать её за производственную систему авторизации и модерации.

## Что переносится
В архиве исходники, интерфейс, изображения, тесты, браузерная среда Pyodide и её лицензии. Нет базы пользовательских изменений, секретов, настроек исходного хостинга и внутренней Git-истории. История чата не входит в архив; эта памятка сохраняет сведения для ближайшей задачи. Исходный опубликованный сайт продолжает работать отдельно.
